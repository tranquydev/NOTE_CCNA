# 🚀 Cisco IOS CLI & Networking Fundamentals - Cheat Sheet & Guide

## 📌 1. Các chế độ làm việc (Modes) trên Cisco IOS

Hệ điều hành Cisco IOS phân chia thành 4 chế độ làm việc chính từ ngoài vào trong:

### 1.1. User EXEC Mode (`Router>`)
* **Dấu hiệu:** `Tên_thiết_bị>`
* **Chức năng:** Chế độ xem cơ bản. Chỉ cho phép kiểm tra một số thông số cơ bản và kết nối mạng đơn giản (`ping`, `traceroute`). Không thể cấu hình/thay đổi thông số.

### 1.2. Privileged EXEC Mode (`Router#`)
* **Dấu hiệu:** `Tên_thiết_bị#`
* **Chức năng:** Xem toàn bộ thông số chi tiết (`show running-config`, mật khẩu, bảng tuyến...), nhưng vẫn **chưa thể trực tiếp sửa đổi cấu hình**.

### 1.3. Global Configuration Mode (`Router(config)#`)
* **Dấu hiệu:** `Tên_thiết_bị(config)#`
* **Chức năng:** Cấu hình toàn cục. Thay đổi các thông số ảnh hưởng toàn thiết bị (đổi tên `hostname`, đặt mật khẩu, mã hóa, banner motd, default-gateway, ip routing...).

### 1.4. Sub-Configuration Modes (`Router(config-xxx)#`)
* **Dấu hiệu:** `Router(config-if)#`, `Router(config-subif)#`, `Router(config-vlan)#`, `Router(config-line)#`...
* **Chức năng:** Cấu hình chi tiết cho từng thành phần/nhánh nhỏ (cổng Interface vật lý, Sub-interface ảo, VLAN ảo, cổng Line Console, Line VTY, v.v.).

## 🔄 2. Sơ đồ chuyển đổi giữa các Mode

```text
       [ User EXEC Mode ]            (Router>)
               │
               │  gõ: enable
               ▼
    [ Privileged EXEC Mode ]         (Router#)
               │
               │  gõ: configure terminal
               ▼
  [ Global Configuration Mode ]      (Router(config)#)
               │
               ├────────────────────────────────────────┐
               │ gõ: interface <tên_cổng>              │ gõ: line console 0
               ▼                                        ▼
    [ Interface Config Mode ]                [ Line Config Mode ]
    (Router(config-if)#)                     (Router(config-line)#)
```

## 🛠️ 3. Các câu lệnh thao tác & Chuyển Mode cơ bản

| Thao tác | Câu lệnh | Từ Mode | Đến Mode / Kết quả |
| :--- | :--- | :--- | :--- |
| **Vào Privileged Mode** | `enable` *(viết tắt: `en`)* | `Router>` | `Router#` |
| **Vào Global Config Mode** | `configure terminal` *(viết tắt: `conf t`)* | `Router#` | `Router(config)#` |
| **Đổi tên thiết bị** | `hostname <tên_mới>` | `Router(config)#` | Prompt đổi tên (VD: `R1(config)#`) |
| **Vào cấu hình Cổng** | `interface <tên_cổng>` *(VD: `interface g0/0`)* | `Router(config)#` | `Router(config-if)#` |
| **Vào cấu hình Sub-interface**| `interface <cổng>.<vlan_id>` *(VD: `fa0/0.50`)* | `Router(config)#` | `Router(config-subif)#` |
| **Vào cấu hình VLAN** | `vlan <ID>` *(VD: `vlan 10`)* | `Switch(config)#` | `Switch(config-vlan)#` |
| **Vào cấu hình SVI** | `interface vlan <id>` *(VD: `interface vlan 30`)*| `Switch(config)#` | `Switch(config-if)#` |
| **Vào cấu hình Console** | `line console 0` | `Router(config)#` | `Router(config-line)#` |
| **Vào cấu hình VTY (Remote)**| `line vty 0 15` | `Router(config)#` | `Router(config-line)#` |
| **Lùi 1 cấp Mode** | `exit` | Bất kỳ Mode nào | Mode cấp trước đó |
| **Thoát thẳng về Privileged**| `end` hoặc tổ hợp `Ctrl + Z` / `Ctrl + C` | Mọi Sub-Config Mode | `Router#` |

## 🏷️ 4. Cấu Hình VLAN, Access, Voice VLAN, Trunk & VTP (Switching)

### 4.1. Xem thông tin VLAN & VTP
```text
Switch# show vlan brief      ! Xem danh sách VLAN và các cổng gán
Switch# show vtp status      ! Xem VTP Mode, Domain Name, Revision Number
```

### 4.2. Cấu hình Cổng Access & Voice VLAN
```text
Switch(config)# interface fastEthernet 0/18
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 20      ! (Data VLAN cho PC)
Switch(config-if)# switchport voice vlan 150     ! (Voice VLAN cho IP Phone)
Switch(config-if)# mls qos trust cos            ! (Ưu tiên QoS thoại)
Switch(config-if)# exit
```

### 4.3. Cấu hình Cổng Trunk & Native VLAN
```text
Switch(config)# interface fastEthernet 0/24
Switch(config-if)# switchport mode trunk
Switch(config-if)# switchport trunk native vlan 99      ! (Đổi Native VLAN sang VLAN 99)
Switch(config-if)# switchport trunk allowed vlan 10,20,99 ! (Danh sách VLAN cho phép)
Switch(config-if)# exit
```

## 🔀 5. Định Tuyến Giữa Các VLAN (Inter-VLAN Routing)

### 5.1. Kỹ thuật 1: Router-on-a-Stick (ROAS)

#### A. Trên Switch (Cổng nối lên Router):
```text
Switch(config)# interface fastEthernet 0/3
Switch(config-if)# switchport mode trunk
Switch(config-if)# exit
```

#### B. Trên Router (Cổng vật lý nối xuống Switch):
```text
Router(config)# interface fastEthernet 0/0
Router(config-if)# no shutdown
Router(config-if)# exit

Router(config)# interface fastEthernet 0/0.50
Router(config-subif)# encapsulation dot1Q 50              ! Đóng gói chuẩn 802.1Q cho VLAN 50
Router(config-subif)# ip address 192.168.50.1 255.255.255.0  ! IP Default Gateway cho VLAN 50
Router(config-subif)# exit

Router(config)# interface fastEthernet 0/0.60
Router(config-subif)# encapsulation dot1Q 60
Router(config-subif)# ip address 192.168.60.1 255.255.255.0
Router(config-subif)# exit
```

---

### 5.2. Kỹ thuật 2: Định tuyến trên Switch Layer 3 (SVI - Switch Virtual Interface)

```text
Switch(config)# vlan 30
Switch(config)# vlan 40
Switch(config)# ip routing                                 ! BẮT BUỘC bật ip routing

Switch(config)# interface vlan 30
Switch(config-if)# ip address 192.168.30.1 255.255.255.0
Switch(config-if)# no shutdown

Switch(config)# interface vlan 40
Switch(config-if)# ip address 192.168.40.1 255.255.255.0
Switch(config-if)# no shutdown
Switch(config-if)# exit

Switch(config)# interface fastEthernet 0/1
Switch(config-if)# switchport trunk encapsulation dot1q   ! Bắt buộc dot1q trên Switch L3
Switch(config-if)# switchport mode trunk
Switch(config-if)# exit
```

## 🌲 6. Giao Thức Chống Vòng Lặp Spanning Tree Protocol (STP & Rapid PVST+)

Giao thức **STP (IEEE 802.1D / 802.1w)** ngăn ngừa hiện tượng lặp Layer 2 (Broadcast Storm).

### 6.1. Kiểm tra trạng thái STP trên VLAN
```text
Switch# show spanning-tree vlan 1
```

---

### 6.2. Cấu hình Root Bridge & Đổi Mode Rapid PVST+ (IEEE 802.1w)

* **Chuyển sang Rapid PVST+ (Hội tụ cực nhanh từ 1s - 3s thay vì 30s - 50s):**
  ```text
  Switch(config)# spanning-tree mode rapid-pvst
  ```

* **Cấu hình Root Bridge ưu tiên:**
  ```text
  Switch(config)# spanning-tree vlan 1 root primary       ! Đặt làm Root Bridge chính
  Switch(config)# spanning-tree vlan 1 root secondary     ! Đặt làm Root Bridge dự phòng
  Switch(config)# spanning-tree vlan 1 priority 24576     ! Đặt giá trị Priority thủ công (bội số của 4096)
  ```

---

### 6.3. Tính năng PortFast & BPDU Guard (Bảo mật cổng Access)

* **PortFast:** Cho phép cổng kết nối xuống PC/Host bỏ qua các trạng thái Listening/Learning để chuyển thẳng sang trạng thái **Forwarding** ngay lập tức.
* **BPDU Guard:** Bảo vệ cổng PortFast. Nếu phát hiện có gói tin BPDU gửi vào cổng (do ai đó cố tình cắm thêm Switch trái phép), cổng sẽ **ngay lập tức bị ngắt mở khoá và đưa vào trạng thái `err-disabled`**.

```text
Switch(config)# interface fastEthernet 0/1
Switch(config-if)# switchport mode access
Switch(config-if)# spanning-tree portfast           ! Kích hoạt PortFast
Switch(config-if)# spanning-tree bpduguard enable   ! Kích hoạt BPDU Guard bảo vệ
Switch(config-if)# exit
```

---

### 6.4. Cách khôi phục cổng bị dính trạng thái `err-disabled`

Khi cổng bị BPDU Guard khóa (trạng thái `err-disabled`), thực hiện mở lại cổng bằng cách gán chuỗi lệnh:

```text
Switch(config)# interface fastEthernet 0/1
Switch(config-if)# shutdown       ! Tắt cổng
Switch(config-if)# no shutdown    ! Bật lại cổng
```

## 🧮 8. Subnet Mask, Wildcard Mask & Quy Hoạch Địa Chỉ Mạng (VLSM)

* **Subnet Mask:** Gồm 32 bit, xác định **Network ID** và **Host ID**. (VD: `/24` $\rightarrow$ `255.255.255.0`, `/27` $\rightarrow$ `255.255.255.224`).
* **Wildcard Mask:** Dùng cho ACL, OSPF. `Wildcard Mask = 255.255.255.255 - Subnet Mask`. (VD: Subnet `/26` $\rightarrow$ `Wildcard = 0.0.0.63`).

| Mạng | Subnet Address | First Usable IP *(Router)* | Second Usable IP *(Switch)* | Last Usable IP *(PC)* | Broadcast |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Room 114 (/27)** | `172.31.103.0` | `172.31.103.1` | `172.31.103.2` | `172.31.103.30` | `172.31.103.31` |
| **Room 279 (/27)** | `172.31.103.32` | `172.31.103.33` | `172.31.103.34` | `172.31.103.62` | `172.31.103.63` |
| **Room 312 (/28)** | `172.31.103.64` | `172.31.103.65` | `172.31.103.66` | `172.31.103.78` | `172.31.103.79` |
| **Room 407 (/28)** | `172.31.103.80` | `172.31.103.81` | `172.31.103.82` | `172.31.103.94` | `172.31.103.95` |
| **Link WAN (/30)** | `172.31.103.96` | `172.31.103.97` | `172.31.103.98` | N/A | `172.31.103.99` |

## 📡 9. Cấu Hình Truy Cập Từ Xa (Remote Access): Telnet vs SSH

```text
! Quy trình 5 bước cấu hình SSH an toàn:
Router(config)# hostname R1
R1(config)# ip domain-name tranquilab.com
R1(config)# username tranquilab privilege 15 secret Ciscopass123
R1(config)# crypto key generate rsa                           ! (Mô-đun 1024 hoặc 2048 bits)
R1(config)# line vty 0 15
R1(config-line)# transport input ssh
R1(config-line)# login local
```

* **Đăng nhập từ Client CMD:** `ssh -l tranquilab 192.168.1.1`

## 💾 10. Bộ Nhớ Cisco & Quản Lý Sao Lưu File Cấu Hình (TFTP Server)

* **RAM:** Lưu `running-config` (Mất dữ liệu khi mất điện).
* **NVRAM:** Lưu `startup-config` (Không mất dữ liệu).
* **Lưu cấu hình:** `copy running-config startup-config` (hoặc `wr`).
* **Reset trắng thiết bị:** `erase startup-config` $\rightarrow$ `reload`.
* **Sao lưu / Khôi phục qua TFTP:** `copy running-config tftp:` / `copy tftp: running-config`.

## 💡 12. Mẹo & Phím Tắt Hữu Ích trong Cisco IOS CLI

> [!TIP]
> * **Phím `Tab`:** Tự động điền đầy đủ câu lệnh.
> * **Dấu `?`:** Liệt kê các lệnh có thể sử dụng tiếp theo.
> * **`Ctrl + C` hoặc `Ctrl + Shift + 6`:** Ngắt lệnh đang chạy (`ping` hoặc ngắt tra cứu domain).
